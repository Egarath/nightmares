04 · ROSTROS DE SHARUUM

Personajes conocidos

Esta sección reunirá proyecciones públicas de PNJ y, cuando cada jugador lo autorice, retratos y perfiles breves de los personajes jugadores.

Los rostros de la mesa están protegidos

Los retratos de PJ existen en el archivo privado, pero están clasificados como revisión privada y no tienen permiso web individual. La web no los copia ni expone nombres, fichas, historias, puntuaciones ni datos SOW.

Estado actual: 0 retratos de PJ autorizados para publicación web.

El expediente público futuro

Cada perfil autorizado podrá incluir nombre visible, retrato consentido, papel conocido, sinopsis breve y fecha de aprobación. El Director, el jugador y el Juez decidirán qué proyección es pública.

Hasta entonces, la ausencia de una galería es deliberada: conserva la privacidad de quienes juegan.

FICHAS PRIVADAS

La hoja de personaje no es un perfil público.

Las fichas se almacenan y validan fuera de GitHub Pages. Esta web nunca muestra su JSON, inventario, conjuros, relaciones, datos de campaña ni credenciales.
